# ladycadmium.net
This is the codebase for my personal website, [ladycadmium.net](https://ladycadmium.net/). This defines things like the page layout, my static blog, and the infocard generator. Please note that this codebase does not include the games and other activities on my site, which are in separate repositories and licensed separately. Built with HTML, Tailwind, and TypeScript (no frameworks).

## Local Development
1) Clone the repository
```
$ git clone https://github.com/ladycadmium/ladycadmium.net
$ cd ladycadmium.net
```
2) Install dependencies
```
$ npm install
```
3) Run the development server (UNIX Only)
```
$ npm run dev
```
The site can be accessed at `http://127.0.0.1:8080/`
4) Build for production
```
$ npm run build
```
